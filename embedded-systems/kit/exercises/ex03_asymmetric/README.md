# ex03 Asymmetric blink on an external LED (pin 5)

An external LED is wired: pin 5 -> 220 ohm -> LED anode, cathode -> GND.
Blink it 100 ms ON and 900 ms OFF. Period T = 1000 ms, duty cycle D = 10 %.

Checked: pin 5 OUTPUT; ON phases 100 ms, OFF phases 900 ms.

Question to answer in your head: with VF = 2 V and 220 ohm, what current flows when the pin is HIGH? ((5-2)/220 = 13.6 mA.)
